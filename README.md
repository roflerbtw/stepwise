# Шаг за шагом / Stepwise

Адаптивный менеджер задач на HTML, CSS и JavaScript. Приложение работает без сборки, сервера данных, авторизации и платных API. Один SVG-знак S используется в обоих языках и в значке вкладки браузера.

## Возможности

- Создание, редактирование, выполнение, поиск, фильтры, избранное и отмена удаления.
- Общий список, задачи на сегодня и интерактивный календарь с добавлением задачи на выбранный день.
- Сроки с отсчётом дней, статистика и круговой прогресс.
- Светлая и тёмная темы, русский и английский интерфейс, анимированные переходы и reduced motion.
- Настройки компактного списка, декоративный робот и окно поддержки с Telegram.
- Хранение задач и настроек в localStorage с проверкой восстановленных данных.

## Запуск

Откройте index.html в современном браузере. Для стабильного адреса и хранилища при установленном Node.js:

```sh
npm start
```

Откройте http://127.0.0.1:4173. Для запуска установка пакетов не требуется.

## Структура

- index.html - разметка и SVG-бренд.
- style.css - оформление, темы, адаптация и анимации.
- ui.js - общие операции с элементами, SVG и датами.
- app.js - состояние, хранение, переводы и список задач.
- calendar.js - всплывающий выбор срока и управление с клавиатуры.
- planner.js - календарь задач и раскрывающаяся форма добавления.
- support.js - окно поддержки и реакции робота.
- favicon.svg - значок вкладки браузера.
- scripts/serve.mjs - локальный сервер для разработки.
- tests/ - проверки логики, взаимодействий и структуры.
- .github/workflows/pages.yml - публикация GitHub Pages.

## Проверки и форматирование

```sh
npm ci
npm test
npm run check
npm run format
```

Инструменты разработки не загружаются пользователям приложения. Проверки включают запуск с настоящей разметкой в jsdom, добавление и редактирование задач, оба календаря, повторное раскрытие панели, фильтрацию, сохранение, отмену удаления, языки, темы, восстановление повреждённых данных и проверку HTML/CSS. Анимации и диалоги в jsdom имитируются: эти проверки не заменяют визуальную проверку в браузере.

## Публикация

В собственном репозитории выберите Settings → Pages → Source: GitHub Actions и отправьте изменения в ветку main. Workflow публикует только файлы приложения. Пути относительные, подходит и для страницы проекта.

Опубликованный сайт: пока не опубликован. Адрес появится после развёртывания в вашем репозитории. Отправка работодателю не выполнялась.

## Хранение и ограничения

Задачи из «Сегодня» и календаря входят в общий список. При переходе разделов поиск и фильтр сбрасываются. Отсчёт срока обновляется при загрузке, возвращении во вкладку и смене дня.

Данные хранятся в текущем браузере на текущем устройстве. Синхронизации и резервного копирования нет. Очистка данных сайта удаляет задачи. Локальный файл, локальный сервер и опубликованный сайт используют отдельные хранилища, задачи автоматически между ними не переносятся.

В браузерах без View Transitions используется CSS-эффект со сменой палитры. При редактировании задачи смена языка недоступна до сохранения или отмены. Кнопка поддержки открывает Telegram @roflerbtw; встроенного чата нет.
